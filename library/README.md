# Skill Library Maintenance

`library/` owns reusable skill-library maintenance, not project production work. `skill-authoring` and its template live here so no production engine privately owns the definition of a reusable skill.

This wave preserves the existing authoring procedure. The proposed Skill Behavior Verification work from issue #24 is intentionally **not implemented** here; it remains a future library-lifecycle candidate requiring its own authority and bounded workstream.
