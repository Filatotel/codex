## Active Canon capability mapping

Historical filenames are not mirrored one-for-one. The migrated Canon Engine consolidates source knowledge into semantic capabilities:

- `establish_canon_foundation`
- `register_canon_fact`
- `register_canon_assumption`
- `register_unknown`
- `register_ambiguity`
- `register_contradiction`
- `reconcile_research_into_canon`
- `classify_canon_change`
- `validate_canon`
- `freeze_canon`
- `reopen_canon`

Required authority chain:

`RESEARCH → EVIDENCE / FINDINGS → CANON RECONCILIATION → ACCEPTED CANON`

Never:

`RESEARCH → automatic Canon mutation`

Canon Foundation captures project truth/intent/protected values/assumptions/unknowns/ambiguities sufficient for a frozen research-entry baseline. It is distinct from Production Foundation, which governs how a specific downstream production is organized and built.
