# Workflow: Reopen Canon

**Workflow ID:** `reopen_canon`

## Entry

- exact frozen Canon state;
- explicit authority to reopen the affected scope;
- reason, impact scope and requested lifecycle mode.

## Procedure

1. Run `reopen-canon` to verify authority and create a new version lineage without altering historical frozen state.
2. For post-2.0 work require one explicit mode: `ADDENDUM`, `EXPANSION`, `NEW_EDITION`, or `REOPEN`.
3. Record prior state ref, proposed scope, reason/evidence, downstream impact and required revalidation.
4. Change the new working scope to an open/proposed state only after the authority gate passes.
5. Route substantive changes through normal registration/reconciliation/change-classification workflows.
6. Validate and freeze the new lineage when its maturity gate is later satisfied.

## Stop

No silent retcon, history rewrite, or authority inference from edit access.
