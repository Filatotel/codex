# Inputs

Exact project identity, supplied Owner/authorized material, authority scope, optional existing Foundation.

# Procedure

1. Inventory explicit intent, protected values, supplied facts, decisions, assumptions and unresolved questions.
2. Label support as explicit decision/supplied fact/inference/unknown; never blur them.
3. Preserve the smallest stable constraints that would materially change project identity if removed; do not force a philosophical thesis or narrative structure.
4. Create stable semantic IDs independent of file/chat location.
5. Initialize 0.x as `PROPOSED` unless explicit authority permits another state.
6. Keep assumptions and unknowns explicit; do not convert missing decisions into intended ambiguity.
7. Record provenance and relevant authority refs.
8. Return a `CANON_FOUNDATION` candidate and required follow-up registrations.

# Stop

Stop if explicit Owner authorities conflict, source evidence is too contradictory for a bounded proposal, or an existing frozen scope would be superseded without change authority.

# Invariant

Creation of a well-formed Foundation creates structure/proposal state, not acceptance authority.
