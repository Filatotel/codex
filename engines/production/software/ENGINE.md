# Engine — Production / Software

## Purpose
Own software-production transformations without absorbing project-wide authority.

## Owns
- software architecture and implementation planning;
- coding, debugging, refactoring, integration;
- data engineering and software persistence implementation;
- release/deployment engineering;
- technical QA and technical evidence production;
- software verification support before independent verification.

## Does not own
- K0 or Owner authority;
- Canon or Research truth;
- universal state/authority/artifact/context definitions;
- other production domains merely because software can represent them;
- final independent acceptance of its own execution result.

## Runtime use
Enter through `MANIFEST.yaml`, select one declared workflow, then load only that workflow's role and bounded skills. Optional Solution Patterns under `patterns/` are loaded only after assumptions and rejection conditions match.

The migrated Codex knowledge is preserved here as an engine, not promoted into root system law.
